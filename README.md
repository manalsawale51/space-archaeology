# Space Archaeology — Mission 001

Multi-page interactive storytelling prototype.

## Publish to your existing GitHub Pages repository
1. Download and extract this ZIP.
2. Open your `space-archaeology` GitHub repository.
3. Upload all contents inside this folder to the repository root, replacing the old `index.html` and adding the other files/folders.
4. Commit changes to `main`.
5. Wait for GitHub Pages to redeploy.

Keep `index.html` at the repository root and preserve the `css/` and `js/` folders.

## Included
Mission control dashboard, mission briefing, expandable timeline, evidence collection, two mini puzzles, illustrative clickable Mars locator, NASA image search links, final verdict, achievement badges and browser localStorage progress. No sound feature is included. Progress is stored only in the current browser and does not sync across devices. The Mars map is illustrative, not geographically precise. Independent educational prototype; not an official NASA product or endorsement.
